# 08. 分阶段执行任务

## 阶段 1：项目重构为全栈 Docker 架构

任务：

- 创建 `frontend/`，迁移现有 React 项目。
- 创建 `backend/`。
- 添加 Express。
- 添加 Prisma。
- 添加 MySQL。
- 添加 `docker-compose.yml`。
- 添加 `.env.example`。
- 修改前端 Nginx，将 `/api` 代理到后端。
- 保证 `docker compose up -d --build` 可启动。

验收：

- `frontend`、`backend`、`mysql` 容器正常运行。
- `/api/health` 返回正常。
- `http://localhost:8080` 能打开前台。
- `http://localhost:8080/admin` 能打开后台入口。

## 阶段 2：认证和真实账号

任务：

- 建立 `admins`、`users` 表。
- 实现 seed 管理员。
- 实现客户注册。
- 实现客户登录。
- 实现管理员登录。
- 实现 `/api/auth/me` 和 `/api/admin/auth/me`。
- 前端接入真实登录态。
- 删除前端管理员假登录逻辑。

验收：

- 新客户注册后写入数据库。
- 管理员 `admin/123456` 可登录。
- 密码字段为哈希。
- 未登录不能访问客户后台。
- 未登录不能访问后台管理页。

## 阶段 3：产品和购买

任务：

- 建立 `products`、`orders`、`wallet_transactions` 表。
- 后台产品 CRUD。
- 前台产品列表读取数据库。
- 客户创建订单。
- 客户余额支付。
- 后台手动充值。
- 后台手动标记订单已支付。

验收：

- 后台新增产品后，前台购买页显示。
- 客户购买后订单入库。
- 余额支付扣款并生成流水。
- 后台充值后客户余额变化。

## 阶段 4：服务器开通和客户后台

任务：

- 建立 `servers` 表。
- 后台录入服务器。
- 后台从订单开通服务器。
- 服务器密码加密保存。
- 客户后台读取真实服务器。
- 客户查看服务器详情。
- 生成开通通知。

验收：

- 后台开通服务器后，订单状态为已开通。
- 客户后台能看到服务器。
- 数据刷新不丢失。
- 数据库不保存明文服务器密码。

## 阶段 5：续费、到期和定时任务

任务：

- 建立 `renewals`、`notifications` 表。
- 实现续费订单。
- 支付续费订单后延长到期时间。
- 实现 worker。
- 实现到期提醒任务。
- 实现过期暂停任务。
- 实现未支付订单取消任务。

验收：

- 修改服务器到期时间后，worker 能更新服务器状态。
- 到期提醒会生成通知。
- 续费后到期时间延长。
- 过期服务器按配置进入暂停状态。

## 阶段 6：工单、代登录、操作日志

任务：

- 建立 `tickets`、`ticket_replies` 表。
- 建立 `impersonation_tokens` 表。
- 建立 `operation_logs` 表。
- 客户提交工单。
- 管理员回复工单。
- 管理员代登录客户。
- 后台关键操作写日志。

验收：

- 客户和管理员可以围绕同一工单回复。
- 管理员代登录 token 一次性有效。
- 后台充值、订单标记支付、服务器开通、代登录都有操作日志。

## 阶段 7：运营验收和文档

任务：

- README 改为真实部署说明。
- 添加数据库初始化说明。
- 添加默认账号说明。
- 添加备份建议。
- 添加常见运维命令。
- 添加最小测试脚本或手动验收清单。

验收：

- 新机器按 README 可以启动项目。
- 管理员能登录后台。
- 客户能注册、购买、查看服务器、提交工单。
- 定时任务容器正常运行。
