# 极云主机管理系统 - 默认数据说明

## 数据初始化方式

项目启动时通过 `backend/prisma/seed.js` 自动初始化数据。Docker 容器启动命令 `npm start` 会自动执行 `prisma db push && node prisma/seed.js && node src/server.js`，即在启动服务前先同步数据库结构并填充种子数据。

种子数据是**幂等**的（使用 `upsert`），多次执行不会产生重复数据。

## 种子数据脚本逻辑

`seed.js` 执行流程：

1. **清理旧演示数据**：如果存在 `demo` 用户（邮箱为 `demo@example.hk`），则级联删除该用户的所有关联数据（订单、服务器、工单、钱包记录等）。

2. **创建/更新管理员**：在 `Admin` 表中 upsert 默认管理员账号。

3. **清理旧种子产品**：将以前版本遗留的种子产品 (`seed-1`, `seed-2`, `seed-3`) 若无关联订单则直接删除，否则设为 `off_sale` 状态。

4. **创建/更新上游数据源**：在 `UpstreamSource` 表中 upsert Fastmos 数据源。

5. **写入系统设置**：逐条 upsert `SystemSetting` 表中的默认配置项。

## 注意事项

- **产品已不再从种子数据生成**。旧版本中有 3 个演示产品，新版本已改为通过上游同步获取产品数据。因此首次启动后，需要在管理后台手动执行上游同步来获取产品列表。
- 如果需要批量导入产品，可通过管理后台的「上游同步管理」功能，从 Fastmos 等上游源拉取数据并选择性发布为本地产品。
- 系统设置可在管理后台（AdminPortal）的「系统设置」面板中动态修改，修改后即时生效，无需重启服务。
