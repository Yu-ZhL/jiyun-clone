# 极云主机管理系统 - 数据库结构说明

## 概述

- **数据库类型**: MySQL 8
- **ORM 框架**: Prisma 6
- **主键策略**: 所有表主键使用 `cuid()` 生成
- **字符集**: 默认 UTF-8（MySQL 默认）

---

## 表关系总览

```
Admin ──┬── WalletTransaction (admin)
        └── OperationLog (admin)

User  ──┬── Order (user)
        ├── Server (user)
        ├── WalletTransaction (user)
        ├── Ticket (user)
        ├── Notification (user)
        └── ImpersonationToken (user)

Product ──┬── Order (product)
          ├── Server (product)
          └── UpstreamServerProduct (product)

UpstreamSource ──┬── UpstreamServerProduct (source)
                 └── UpstreamSyncRun (source)

Order ──┬── Server (order)
        ├── WalletTransaction (order)
        ├── Renewal (order)
        └── Notification (order)

Server ──┬── Order (server)
         └── Renewal (server)

Ticket ──── TicketReply (ticket)
```

## 重要说明

1. **金额存储**：所有金额（余额、价格、交易金额）均以「分」为单位存储为整数，避免浮点精度问题。
2. **密码加密**：管理员/用户密码使用 bcrypt (12轮) 哈希存储；服务器登录密码使用 AES-256-GCM 加密存储在 `loginPasswordEncrypted` 字段中。
3. **主键生成**：所有主键使用 `cuid()` 生成，非自增整数。
4. **数据库同步**：使用 `prisma db push` 命令同步 Schema 到数据库，而非 Migration 方式。
